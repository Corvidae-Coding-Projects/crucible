# Support

Crucible is an active pre-release implementation with a normative design specification. Its initial
Linux CLI control plane is executable and tested, but it is not yet a supported production release.

Use the following channels:

- [GitHub Discussions](https://github.com/Corvidae-Coding-Projects/crucible/discussions) for
  questions, design exploration, implementation coordination, and community support.
- [GitHub Issues](https://github.com/Corvidae-Coding-Projects/crucible/issues) for reproducible
  repository defects and scoped proposals using the provided forms.
- [Private vulnerability reporting](https://github.com/Corvidae-Coding-Projects/crucible/security/advisories/new)
  for security-sensitive reports.

Before asking for help:

1. Read the [README](README.md), [specification index](crucible.md), and [roadmap](ROADMAP.md).
2. Search existing issues and discussions.
3. Identify the exact document section, revision, target class, or planned phase involved.
4. Provide evidence, constraints, and the desired outcome without including secrets or private
   target data.

Maintainers cannot provide help exploiting third-party software, bypassing authorization, or
turning correctness findings into offensive tooling.
